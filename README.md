# Table2Eat

A sandbox restaurant website — fresh minimalist bistro landing page with an integrated GSAP-animated table reservation flow (details → QR payment → receipt upload), plus a staff admin portal for tracking bookings and managing inventory.

## Live Site

- Customer site: `index.html`
- Staff portal: `admin/index.html` (demo login: `admin` / `table2eat`)

## Notes

This is a front-end sandbox/demo project. Booking and inventory data are stored in the browser's `localStorage` — no backend is wired up yet.
